라이브 데모 ↗ GitHub ↗

제8회 첨단산업·디지털 핵심 실무인재 양성훈련 해커톤 · 자유과제 부문 · 팀 공장수호대(김현진·김가람·박은희·정재승·정재영)

제스처·음성·위험구역 접근을 동시에 감지하는 트리플 트리거 방식의 안전 정지 시스템입니다. 감지 → RAG → Vision LLM 파이프라인으로 사고 리포트까지 자동 생성합니다.

  • YOLO(yolo26n)로 사람을 탐지해 위험구역 폴리곤과의 겹침 비율로 접근 판정 — 초기 OpenCV 배경차분(MOG2)은 벨트 움직임 오탐·정지 인물 미검출 문제가 있어 실측 테스트 후 YOLO로 전환
  • 이벤트 발생 프레임만 OpenAI Vision API(GPT-4o-mini)로 분석해 상황 요약·위험도·근거 생성(15초 쿨다운으로 비용 관리), 사고 이미지 기반 6개 항목 리포트 API 구현
  • RAG가 검색한 법령 근거만으로 리포트를 작성하도록 프롬프트 설계 — 근거 없는 조항·수치 생성 방지, 파이프라인 실패 시에도 감지 흐름이 끊기지 않도록 예외 처리
  • 팀장으로 기획 총괄 및 발표 자료·발표 대본 제작

교통봇 — 음성 기반 대중교통 안내

GitHub ↗ 데모 영상 ↗

호출어와 음성 질문만으로 실시간 버스 도착 정보를 안내하는 서비스입니다. KWS(호출어 인식) 파인튜닝을 담당해 정확도 97%를 달성했고, 출근 시간대 빠른 확인과 시각이 불편한 사용자의 접근성 개선을 목표로 했습니다.

  • openWakeWord 파인튜닝으로 호출어 "교통봇" 감지 모듈 개발 — Positive 200개를 직접 녹음·증강해 1,000개로 확장, Negative 1,325개와 연속 4회 감지 방식으로 오탐 최소화
  • 초기 호출어 "교통안내"는 일상 대화와 발음이 유사해 오탐이 잦았음 — "교통봇"으로 변경하고 유사 발음 네거티브 데이터를 추가해 재학습
  • Whisper STT + Levenshtein 유사도로 정류소명 인식 보완, 광주광역시 BIS 공공데이터 API 연동 (문서현)
  • GPT-SoVITS TTS를 API 서버로 상주시켜 응답 20초 → 1~3초, Cloudflare Tunnel로 외부 접근 구성 (김가람)

Project Junhyuk — 감성 상담 챗봇

GitHub ↗

친구처럼 편하게 마음을 나눌 수 있는 감성 상담 챗봇입니다. EXAONE-3.0-7.8B를 감정 상담 데이터로 파인튜닝하고, RAG로 유사 상담 사례를 검색해 공감도 높은 응답을 생성합니다.

  • LGAI EXAONE-3.0-7.8B-Instruct를 QLoRA(r=16, alpha=32)로 파인튜닝 — 12개 감정 카테고리, 981개 대화 데이터 학습 (loss 0.3047)
  • ChromaDB + KR-SBERT 임베딩으로 RAG 구축 — 유사 대화 예시 3개를 few-shot으로 system prompt에 주입
  • temperature·repetition_penalty 등 생성 파라미터 튜닝, 체크포인트별 loss 비교로 응답 품질 검증
  • RAG 서버를 별도 프로세스로 분리해 API 형태로 서비스 구성
