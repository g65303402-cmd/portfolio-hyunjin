교통봇 — 음성 기반 대중교통 안내 서비스

팀 프로젝트 · 음성 AI (김현진 · 문서현 · 김가람) · 2026.04.16 ~ 04.29

호출어와 음성 질문만으로 실시간 버스 도착 정보를 안내하는 서비스입니다. 출근 시간대 빠른 정보 확인과 시각이 불편한 사용자의 접근성 개선을 목표로 개발했습니다.

  • KWS(호출어 인식) 파인튜닝 담당 — 직접 녹음한 200개 데이터를 증강해 약 1,000개 학습 데이터 구축, 네거티브 데이터 학습과 연속 4회 감지 방식으로 오탐을 줄여 호출어 인식 정확도 0.97 달성
  • Whisper 기반 STT + Levenshtein 유사도 비교로 정류소명 인식 오류 보완, 광주광역시 BIS 공공데이터 API 연동 (문서현)
  • GPT-SoVITS 기반 TTS를 API 서버로 상주시켜 응답 시간을 20초에서 1~3초로 단축, Cloudflare Tunnel로 외부 접근 구성 (김가람)

04

Project Junhyuk — 친구같은 감성 상담 보조자

팀 프로젝트 · 대화형 AI

친구처럼 편하게 마음을 나눌 수 있는 감성 상담 챗봇입니다. EXAONE-3.0-7.8B 모델을 감정 상담 데이터로 파인튜닝하고, RAG로 유사 상담 사례를 검색해 공감도 높은 응답을 생성합니다.

  • LGAI EXAONE-3.0-7.8B-Instruct를 QLoRA(r=16, alpha=32)로 파인튜닝 — 12개 감정 카테고리, 981개 대화 데이터로 학습
  • ChromaDB + KR-SBERT 임베딩으로 RAG 구축 — 유사 대화 예시 3개를 few-shot으로 system prompt에 주입
  • temperature·repetition_penalty 등 생성 파라미터 튜닝 및 체크포인트별 loss 비교로 응답 품질 검증
  • RAG 서버를 별도 프로세스로 분리해 API 형태로 서비스 구성
